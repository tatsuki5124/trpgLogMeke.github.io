# File Summarizer

Explore サブエージェント（Haiku・read-only）を fork コンテキストで起動し、タスクに関連するファイルの生情報を収集する。

## 使用タイミング

- 実装前: 関連エリアにどんなファイルがあるかを把握する
- レビュー前: 変更されたファイルの現状を把握する
- ゲート判定前: 何が変更されたかを収集する

## 呼び出し方

以下を提供する:
1. **スコープ**: 検索する glob パターンまたはディレクトリパス（例: `src/logmake/lib/**/*.ts`）
2. **タスク文脈**: 何を理解しようとしているか（何を探すかを Explore に伝える）

## Explore が収集するもの

- スコープに一致するファイルリスト
- 主要なエクスポート（関数・型・定数）
- 関連ファイルの import グラフ
- `git diff` 情報（利用可能な場合）

## 出力

Analyzer への入力となる生の構造化サマリーを出力する。この出力を実装判断に直接使わない——必ず Analyzer を通して凝縮してから使う。

## 注意事項

- Explore は read-only: このフェーズ中にファイル変更は発生しない
- fork コンテキスト: メインの会話コンテキストを汚染しない
- スコープは狭く指定する——広い glob はトークン消費と速度低下を招く
