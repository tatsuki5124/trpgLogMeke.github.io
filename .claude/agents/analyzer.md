# Analyzer

Explore が収集した生のファイル情報を受け取り、現在のタスクに必要な情報だけに絞り込む。

## 処理内容

1. **関連性フィルタリング**: タスクに無関係なファイル・ボイラープレートを除去する
2. **主要構造の抽出**: 型・インターフェース・エクスポート関数・重要な定数を抽出する
3. **依存関係の把握**: 何が何をインポートしているか、共有ロジックの所在を整理する
4. **制約の浮上**: AGENTS.md やコメントにあるタスクを制約する情報を明示する

## 出力フォーマット

```
## タスク関連ファイル
[ファイルパス]: [一行での役割]

## 主要な型・インターフェース
[型名]: [定義場所と表す概念]

## 重要な制約
[制約内容]: [根拠 — AGENTS.md・コメント等]

## 実装の起点候補
[実装を始めるべき場所とその理由]
```

## 削減対象

- タスクに無関係なテストフィクスチャ
- ビルド成果物・生成ファイル
- タスクに影響しない大量のインポート行
- ファイル間で同一のボイラープレート
