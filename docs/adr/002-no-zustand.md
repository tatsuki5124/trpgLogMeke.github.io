# ADR-002: 状態管理に Zustand を採用しない

**状態**: 採用

## 判断

グローバル状態管理ライブラリ（Zustand 等）を導入せず、`useLogmakePageState` カスタムフックで状態を一元管理する。

## 理由

- コンポーネント階層がフラットで、深い props のバケツリレーが発生していない。
- 複数ページ間での状態共有が不要（logmake は単一ページで完結）。
- localStorage による設定永続化もまだ不要。
- 派生値は `useMemo` で十分に対応できている。

## 代替案

- **Zustand**: 軽量で導入しやすいが、現時点では解決すべき問題がない。
- **Redux / Jotai**: 同上。オーバーエンジニアリングになる。

## 再検討の条件

以下のいずれかが発生した場合に再検討する:

- props のバケツリレーが 3 階層を超える
- 複数ページ間で状態を共有する必要が出る
- localStorage による設定永続化を実装する
