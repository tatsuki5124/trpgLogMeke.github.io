# ADR-001: Vue から React への移行

**状態**: 採用

## 判断

旧 Vue 版（`legacy/`）を廃止し、React + TypeScript で全面的に書き直す。

## 理由

- **保守性**: Vue 版はコードの見通しが悪く、機能追加・バグ修正のコストが高かった。ビジネスロジックと UI が密結合しており、テストも書きづらかった。
- **学習**: React / TypeScript のスキル習得を兼ねたプロジェクトとして再構築する動機があった。
- **設計改善の機会**: 移行に合わせて、純粋関数への分離（`lib/`）、ゲームシステム抽象化（`systems/`）、テスト戦略の導入など、アーキテクチャを根本から見直せた。

## 代替案

- **Vue 版を改善**: 既存コードの段階的リファクタリング。しかし密結合が深く、部分的な改善では限界があった。
- **他のフレームワーク（Svelte 等）**: 検討したが、エコシステムの成熟度と学習目的の両面で React を選択。
