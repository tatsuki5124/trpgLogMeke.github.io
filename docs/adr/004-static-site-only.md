# ADR-004: 完全静的サイト（バックエンドなし）

**状態**: 採用

## 判断

すべての処理をブラウザ側で完結させ、バックエンドサーバーを持たない。ユーザーのログデータをサーバーに送信しない。

## 理由

- **セキュリティ**: TRPG のセッションログには個人的な会話が含まれる。サーバーにデータを送信しないことで、情報漏洩リスクをゼロにする。
- **運用コスト**: GitHub Pages での無料ホスティングで完結する。サーバー運用の手間とコストが不要。
- **プライバシー**: ユーザーのファイルはブラウザのメモリ上でのみ処理され、外部に送信されない。

## 代替案

- **サーバーサイド処理**: ログ解析をサーバーで行えばブラウザ負荷を下げられるが、セキュリティ・プライバシーのリスクとインフラコストが発生する。
- **Firebase 等の BaaS**: ユーザー設定の保存には便利だが、現時点では不要。必要になれば localStorage で対応する。
