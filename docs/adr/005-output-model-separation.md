# ADR-005: OutputModel によるダウンロード HTML 生成

**状態**: 採用

## 判断

ダウンロード用 HTML の生成を `OutputModel` という中間データ構造を経由して行う。画面プレビューと出力 HTML を分離する。

## 理由

- 画面上の React コンポーネントと配布用 HTML は構造・スタイルが異なる。プレビューと出力を同一にすると、どちらかに最適化したときにもう片方が崩れる。
- `OutputModel` を純粋なデータ構造にすることで、HTML レンダリング（`buildOutputHtml`）をテスト可能な純粋関数として実装できる。
- 将来の縦書き HTML / PDF 出力も `OutputModel` から別のレンダラーを通す形で拡張できる。

## 代替案

- **React コンポーネントを直接 HTML 化**: `renderToStaticMarkup` 等で React ツリーをそのまま出力する方法。CSS の扱いが煩雑になり、配布用 HTML としての品質制御が難しい。
- **テンプレートエンジン**: Handlebars 等を別途導入する方法。依存が増える割に、文字列連結で十分な用途。
