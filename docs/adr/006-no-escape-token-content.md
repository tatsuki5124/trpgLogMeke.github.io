# ADR-006: トークンコンテンツの非エスケープ

**状態**: 採用

## 判断

`renderToken` で `token.content` に `escapeText()` を適用しない。CCFOLIA の innerHTML をそのまま出力 HTML に通す。

## 理由

- CCFOLIA のログにはインライン書式（`<b>`, `<i>` 等）が含まれる。`escapeText()` を適用するとこれらの書式が壊れ、ユーザーが意図した装飾が失われる。
- 入力ソースが CCFOLIA の出力 HTML に限定されているため、任意の悪意あるスクリプトが混入するリスクは低い。
- 出力 HTML はダウンロードしてローカルで閲覧する用途のため、XSS の影響範囲が限定的。

## 代替案

- **全エスケープ**: 安全だが、CCFOLIA のインライン書式がすべて壊れる。ユーザー体験の劣化が大きい。
- **ホワイトリスト方式のサニタイズ**: `<b>`, `<i>` 等の安全なタグのみ許可する方法。将来的に検討の余地はあるが、現時点では CCFOLIA 出力に限定されるため過剰。

## 注意

将来「セキュリティ修正」として誤ってエスケープを追加しないこと。この判断は意図的なものであり、AGENTS.md にも記載済み。
