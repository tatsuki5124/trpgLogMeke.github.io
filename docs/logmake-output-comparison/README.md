# ログ出力比較

同一の比較用 fixture から、横書き出力の見え方を比較するためのHTMLを生成する。

検討中の論点は [ログ出力表示 議論項目メモ](./discussion-topics.md) にまとめる。

```bash
pnpm logmake:compare-output
```

生成されるファイル:

- `speaker-after-line.html`: 人物本文は標準色のまま、名前の後ろから短いキャラクター色ラインを伸ばす案。
- `speaker-body-guide.html`: 人物本文は標準色のまま、本文幅を削らずに発言本文の左側へ薄いキャラクター色ガイドを引く案。KP/GM/空話者の地の文にはガイド線を出さない。
- `candidate-combined.html`: 名前下線を軸に、KP/GM/空話者の地の文を左バーなしで控えめに表示し、情報ブロックをやや濃くする統合候補。
- `*-dark.html`: 各案のダークモード確認用。
- `index.html`: 各案を iframe で並べる確認用ページ。

評価時は、誰の発言か追えるか、補助タブの範囲が分かるか、本文色が長文読解を邪魔しないか、成功/失敗ハイライトが埋もれないかを見る。
特に本文色と発言境界は、`speaker-after-line` / `speaker-body-guide` / `candidate-combined` を見比べる。

統合候補では、追加で以下も確認する。

- 人物発言は名前のみキャラクター色、本文は標準文字色にする。
- 名前下線が、本文や補助タブ境界と衝突しないかを見る。
- 場面タイトルは場面転換の見出しとして扱い、特に上側に十分な余白を取る。
- 場面名ありは h3 見出しを維持し、その後の描写本文は地の文色に合わせる。KP/GM/空話者など場面名なしの場面は少し控えめな文字色にする。
- タブ内の情報ブロックは上下余白を詰める。
- タブブロック内は左右paddingを広げすぎず、通常発言とのインデント差が大きくならないかを見る。
- 情報ブロックの枠線・タイトル・本文はライトでは少し濃く、ダークでは少し明るくする。
- 成功/失敗マーキングは、案ごとの差分軸にしない。ダークモードでは本文可読性を優先して少し半透明にする。
- 日本語本文の折返しは `word-break: auto-phrase` を使い、分かち書きの読みやすさと細い幅での崩れ方を見る。

比較fixtureには、GM発言、空話者の地の文、ラベル付き場面、低コントラスト色・強彩度色の人物発言、長文人物発言、補助タブ内の人物発言と情報ブロックを含める。
ラベル付き場面と色確認用の人物発言は、比較用モデル生成時だけ表示種別を固定し、production の自動判定は変更しない。

## 確定事項

- 本文はキャラクター色なし（標準色）。`candidate-colored-body` 案は除外。
- タブブロックの背景色は必須。
- 横書き情報タイトル位置は `left: .5rem`（比較用・production 共通）。
