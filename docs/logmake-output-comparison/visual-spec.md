# 視覚表示仕様書（比較案ベース）

比較案（candidate-combined）における全視覚要素の仕様と設計意図の記録。
実装は `src/logmake/test/outputVisualComparison.ts` / `src/logmake/lib/defaults.ts` を参照。

production（`src/logmake/lib/buildOutputHtml.ts`）はクラス名・構造が旧 Vue 版由来のまま残っており、
ここに記載する仕様は比較案を基準とした「目指すべき形」として扱う。

---

## 1. ページ枠組み

### 固定ヘッダー

- 背景色: `frameColor`（ライト: `#6b8e23`、ダーク: `#2c3e50`）
- タイトル `h1`: `nameColor`（ライト: `#ffffff`、ダーク: `#c8c8c8`）、フォント: New Tegomin
- タブ切り替えラベル: `nameColor`
- チェックボックスの accent-color: `var(--log-tab-color)`（タブ色に追従）

**意図**: ヘッダーは frameColor で統一し、ログ本体（白背景）と視覚的に切り離す。
タイトルとチェックボックスラベルを nameColor にすることで、frameColor 上での視認性を確保する。

### ログフレーム（`.log-frame`）

- 背景色: `#ffffff`（ダーク: `#2d2d2d`）
- 枠線: `border: double 5px frameColor`
- 内側余白: `padding: 2rem`（モバイル: `0.8rem`）
- 外側余白: `margin: 6rem 2rem 2rem`（上 6rem はヘッダー分の確保）

**意図**: 白背景でログ本文を frameColor の枠の中に収め、「配布物としてのまとまり」を与える。
二重枠（double）は装飾的意図。ただし frameColor に近い色設定になりやすく、視認されないケースがある。
廃止も検討対象（→ `discussion-topics.md` 参照）。

## 2. タブセクション

### メイン・情報セクション（`.log-section--primary`）

- 背景色: なし（`log-frame` の白が透けて見える）
- 境界線: なし

**意図**: ログ本文のデフォルト状態として装飾を持たない。
補助タブとの対比で「通常のログ」を示す基準面とする。

### 補助タブセクション（`.log-section--tab`）

- 背景色: `rgba(127,127,127,0.1)`（ダーク: `rgba(200,200,200,0.06)`）
- 左ボーダー: `border-inline-start: 3px solid var(--log-tab-color)`
- タブ色: タブ名のハッシュから 8 色パレットで安定決定
  ```
  #8e5c5c / #597da7 / #6e8e3d / #9c6a2e / #7164a9 / #567f83 / #ab5a7b / #8c7a45
  ```
- タブ名ラベル（右上）: `color: var(--log-tab-color)`、`opacity: .45`、`font-size: .75rem`、`pointer-events: none`
- 内側余白: `padding: 1.5rem .75rem 1rem`
- 外側余白: `margin: 1.5rem 0`

**意図**: グレー薄塗り + 左ボーダーで「ここは補助タブの範囲」を示す。
左ボーダーの色をタブ色にすることで、どのタブに属するか識別できる。
タブ名ラベルは opacity .45 で控えめにし、本文の邪魔にならないようにしている。

**確定事項**: タブブロックの背景色は必須。背景なし（左ボーダーのみ）には戻さない。

## 3. キャラクター発言（`.log-entry--speaker`）

- 外側余白: `margin: 1.7rem 1rem 1.7rem .5rem`

### 話者名（`.log-speaker`）

- `color: var(--log-speaker-color)`（CCFOLIA のキャラクター色）
- `font-weight: bold`
- `display: block`

**candidate-combined 限定 — 名前下線マーカー（`::after`）:**

- `border-block-end: 2px solid var(--log-speaker-color)`
- `opacity: .48`

**意図**: 名前と本文の境界を示しつつ、太字のみでは弱い「発言ブロックの始まり」を補強する。
下線は `border-block-end` で記述するため横書き・縦書きで物理方向が変わるが、縦書き時は要確認。
リンクと誤認されないよう、opacity .48 で線を控えめにしている。

### 本文（`.log-message`）

- `color: #333333`（ダーク: `#d0d0d0`）
- `padding: .5rem`

**確定事項**: 本文色はキャラクター色なし（標準色固定）。

## 4. 成功・失敗ハイライト

ダイス結果テキストを含む `<span>` の `background` として直接適用する。
テキスト色は本文色（`#333333`）のまま変更しない。

| モード | 成功 | 失敗 |
|---|---|---|
| ライト | `linear-gradient(transparent 70%, #7fbfff 0%)` | `linear-gradient(transparent 70%, #ff7f7f 0%)` |
| ダーク | `linear-gradient(transparent 70%, rgba(127,191,255,0.56) 0%)` | `linear-gradient(transparent 70%, rgba(255,127,127,0.58) 0%)` |

**意図**: テキスト下部 30% に色帯を引き、蛍光ペンのような視覚効果を出す。
テキスト上部 70% を透明のまま保つことで、本文の可読性を損なわない。
縦書き時は帯の向きが崩れるため、縦書き専用の gradient（`to right` 方向）に切り替える仕組みが production には既にある。

**ダーク時のみ `rgba` で半透明化している理由**: ダーク背景では完全不透明の色帯が強すぎるため。
ライトは元の `#7fbfff` / `#ff7f7f` を維持。ダーク時の最終 opacity は未決（現在 0.56 / 0.58）。

## 5. 場面タイトル（`.log-entry--scene`、場面名あり）

- `h3.log-scene`: `margin: 2rem 0 .65rem .5rem`、`color: var(--log-speaker-color)`
- 本文（`.log-message`）: `color: #555555`（ダーク: `#b8b8b8`）= narrationColor
- 背景なし
- 枠・ボーダーなし

**意図**: 場面タイトルは「そのブロックのタイトル」として機能させたいため、
発言者名と同様に `.5rem` のインデントで左端に近い位置に配置する。
（発言者名 = `.5rem`、地の文 = `1rem` より前にある）

上余白 `2rem` で前後の発言と区切りを作るが、キャラクター発言の `1.7rem` との差は約 `0.3rem` にとどまる。
スクロール中に知覚できる差としては不十分であり、強調方法は検討中（→ 後述の未決事項）。

## 6. 地の文（`.log-entry--narration`、KP・GM・話者なし）

- 外側余白: `margin: .65rem 1rem .65rem .5rem`
- テキスト色: `#555555`（ダーク: `#b8b8b8`）= narrationColor
- 比較案では名前ラベルなし（話者名を非表示にした状態で描画）
- 背景なし・枠なし

**意図**: 地の文は発言と発言の間に流れるように挟まる要素として、
余白を詰め（`0.65rem`）発言ブロックより軽い視覚的重みにしている。
narrationColor（`#555555`）を使い標準色（`#333333`）より低コントラストにすることで、
PC 発言が浮き上がって見える構造を作る。

**検討中**: この余白値・色の組み合わせが最適かどうかは未決。
特に場面タイトルとの余白の関係（場面タイトル上 `2rem` に対し、直前の地の文下 `0.65rem`）は要調整。

## 7. 情報ブロック（`.log-entry--info`）

- 外側余白: `margin: 1.75rem 1.25rem 1.5rem`
- 補助タブ内では: `margin: 1.1rem .75rem .95rem`（タブ内は上下を詰める）
- 内側余白: `padding: 1rem 1.5rem .5rem 1rem`
- 背景色: `${back}`（= `log-frame` と同じ `#ffffff` / `#2d2d2d`）
- 枠線: `border: solid 3px #707070`（ダーク: `#a8a8a8`）、`border-radius: 8px`

### 情報タイトル（`.log-info-title`）

- `position: absolute; top: -0.6rem; left: .5rem`（枠の上辺に重ねて浮かせる）
- 背景色: `${back}`（= 枠線の上から白で塗り潰して「浮き出し」効果を作る）
- `color: #707070`（ダーク: `#a8a8a8`）
- `font-weight: bold`、`font-size: 1rem`

**意図**: タイトルを枠の上辺に「浮かせる」ことで、ブロックの内容を一目で示す。
背景色を `back` と同色にするのは、枠線の一部をタイトルで隠すため（線を隠したい）。

**既知の副作用**: 補助タブ内に情報ブロックが置かれると、
タブのグレー背景の上に情報ブロックの白背景が乗り、意図せず「浮いた」印象になる。
これはタイトルの浮き出し実装の構造的な副作用であり、解消方法は未決。

**確定事項**: 情報タイトルの横位置は `left: .5rem`。

### 本文

- `color: #707070`（ダーク: `#a8a8a8`）

## 10. 未決・要議論

### 場面タイトルの強調不足

現状の `h3 margin-block-start: 2rem` はキャラクター発言（`1.7rem`）との差が約 `0.3rem`（≒ 5px）にとどまる。
スクロール中の場所探しには不十分。
背景色はタブ・情報ブロック・ハイライトで既に意味付けされているため追加困難。
`border-block-start`（上ボーダー）+ 余白拡大が現実的な強調手段として検討中。

### 地の文の余白・色の最終値

`margin: .65rem` および `narrationColor` の組み合わせは調整中。
場面タイトルとの上下余白の関係が最適かどうか未決。

### 情報ブロックのタブ内での浮き問題

補助タブ背景（グレー）の上に情報ブロックの白背景が乗ると視覚的に浮いて見える。
解消手段として情報ブロックの背景を透明化することも考えられるが、
タイトルの浮き出し効果（線を隠す）が成立しなくなる。

### 情報タブの扱い

現状、「情報」タブはメインタブと同等（`isPrimaryTab`）として扱われ、補助タブのグレー背景・左ボーダーが付かない。

しかし CCFOLIA では「情報タブをピン留め（メモ帳）として使い、同じ内容をメインタブにも流す」利用者が多い。
そのため配布 HTML に情報タブとメインタブで全く同じ内容が重複して出力されるケースがある。

検討候補:
- 重複内容を情報タブ側で省略する（内容が同じエントリを自動検出）
- 重複表示をオプション設定でオン/オフできるようにする
- 情報タブとその他補助タブを同等扱いにするかどうかも再検討の余地あり

### 成功・失敗ハイライト opacity（ダーク時）

現在 `0.56` / `0.58`。最終値は未決。
下げすぎるとハイライトが埋もれる。

### 名前下線 opacity

現在 `0.48`。リンクと誤認されないための値だが、最終値は未決。
